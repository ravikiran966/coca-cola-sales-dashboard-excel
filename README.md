# 🥤 Coca-Cola Sales Performance Analysis Using Microsoft Excel

## 📌 Project Overview

This project presents an interactive **Coca-Cola Sales Performance Dashboard** developed using **Microsoft Excel**. The dashboard analyzes sales, profitability, retailers, regions, and beverage brands to provide meaningful business insights that support data-driven decision-making.

Using PivotTables, PivotCharts, KPI Cards, and Slicers, the dashboard enables users to explore sales performance dynamically across multiple business dimensions.

---

## 🎯 Project Objective

The objective of this project is to:

- Analyze Coca-Cola sales performance.
- Identify the highest and lowest sales months.
- Compare sales across retailers and regions.
- Analyze beverage brand performance.
- Evaluate operating profit and operating margin.
- Build an interactive dashboard for business users.

---

## 📂 Dataset

The dataset contains Coca-Cola sales transactions from multiple retailers across different regions in the United States.

### Key Columns

- Invoice Date
- Retailer
- Region
- State
- City
- Beverage Brand
- Price per Unit
- Units Sold
- Total Sales
- Operating Profit
- Operating Margin

## 📌 Key Insights

- Sales increase significantly during the second half of the year.
- The West region generated the highest sales.
- Coca-Cola is the highest-selling beverage brand.
- Some retailers consistently outperform others.
- Seasonal demand influences beverage sales across all brands.

## 💡 Business Recommendations

- Increase inventory before peak sales months.
- Focus marketing efforts on lower-performing regions.
- Strengthen partnerships with top-performing retailers.
